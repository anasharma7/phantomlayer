# Ana Sharma — Cyber + AI Platform

Futuristic personal research platform: cyber intelligence archive, AI-era media identity, and experimental lab.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- shadcn/ui

## Requirements

- **Node.js ≥ 20.9.0** (see `.nvmrc`)

```bash
nvm use
```

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

See [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md).

## Deploy

Push to GitHub and connect to [Vercel](https://vercel.com). No extra config required.
